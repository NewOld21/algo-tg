## 1. allSum (전체 구간 합)
Parent 구간 전체를 커버합니다.
```
[start ========== mid] [mid+1 =========== end]
└─────────────── Left + Right ───────────────┘
```

## 2. leftMax (왼쪽 끝 [start]를 반드시 포함하는 구간)
start에서 출발하여 어느 지점까지 늘어나는지 보여줍니다.
```
Option A (왼쪽 안에서 끝남):
[start ==========> ...... mid] [mid+1 ................ end]
└─ Left.leftMax ─┘

Option B (경계를 넘어 오른쪽까지 침범):
[start ================== mid] [mid+1 ==========> .... end]
└────── Left.allSum ─────────┘ └─ Right.leftMax ─┘
```

## 3. rightMax (오른쪽 끝 [end]를 반드시 포함하는 구간)
end에서 출발하여 왼쪽으로 어디까지 늘어나는지 보여줍니다.
```
Option A (오른쪽 안에서 끝남):
[start ................. mid] [mid+1 ...... <============= end]
                                           └─ Right.rightMax ─┘

Option B (경계를 넘어 왼쪽까지 침범):
[start ..... <========== mid] [mid+1 ==================== end]
            └ Left.rightMax ┘ └─────── Right.allSum ─────────┘
```

## 4. maxSum (구간 내 존재 가능한 최대 연속 부분합)
어느 위치에 걸쳐있는지 3가지 케이스를 나타냅니다.
```
Option 1 (왼쪽 내부에 독립 존재):
[start ..... [======] ..... mid] [mid+1 ...................... end]
             Left.maxSum

Option 2 (오른쪽 내부에 독립 존재):
[start .................... mid] [mid+1 ..... [======] ....... end]
                                              Right.maxSum

Option 3 (경계선 mid | mid+1 을 다리처럼 연결):
[start ........... <======= mid] [mid+1 =======> ............. end]
                  Left.rightMax + Right.leftMax
```
